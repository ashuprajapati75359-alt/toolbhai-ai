# ToolBhai AI — Starter MVP

A static Hindi + English utility tools website designed for a very low starting budget.

## Included
- Responsive homepage
- Hindi/English toggle
- Tool search + category filters
- Age calculator
- EMI calculator
- GST calculator
- Percentage calculator
- Word counter
- Image compressor
- Image resizer
- QR code generator
- AI prompt generator (template-based; no paid API)
- YouTube title generator (template-based)
- Social caption generator (template-based)
- Privacy, Terms and Disclaimer pages
- robots.txt + sitemap.xml starter

## Publish for free
1. Create a GitHub account and a new repository.
2. Upload all files from this folder.
3. Enable GitHub Pages, or import the repository into Netlify / Cloudflare Pages.
4. Replace `YOUR-DOMAIN.com` in `robots.txt` and `sitemap.xml` after you get a domain.

## Before applying for AdSense
- Add original About and Contact details.
- Publish useful original articles, not copied text.
- Add more genuinely useful tools/pages.
- Make sure all navigation and policy pages work.
- Connect Search Console and submit the sitemap.
- Do not expect guaranteed earnings; traffic and approval are required.

## QR tool note
The QR generator uses QuickChart's public QR endpoint, so that one feature needs internet access.
